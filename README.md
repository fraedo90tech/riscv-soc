# riscv-soc
This respo has been created to track the progress of my self-initiated RISC-V based SoC system that I will be designing and implementing on a Terasic DE2-115 FPGA development board which uses the Altera Cyclone IV chip. Using the RV32I ISA I will be designing each computer module in SystemVerilog and writing test benches using Python and the CocoTB Python library.
